# 정무상황실 v1

국회와 정부를 대상으로 한 정무 워게임 도구. 판단마다 근거(기록·보도·규칙·선례·AI 추정)를 화면에 표시한다.

- 처음 시작: [docs/keys.md](docs/keys.md) (키 발급 → 설치 → 실행, 복사해서 따라 하기)
- 진행 상황: [PROGRESS.md](PROGRESS.md)
- 사용하는 API: [docs/apis.md](docs/apis.md)

## 한 줄 실행

```
python run.py
```
→ 브라우저에서 http://127.0.0.1:8000

## 구성

| 경로 | 내용 |
|---|---|
| `src/update_assembly.py` | 22대 국회 의원·법안·표결 수집, 매일 증분 갱신 (`data/assembly.sqlite`) |
| `src/check_apis.py` | 열린국회정보 API 실호출로 서비스 코드·필드 확인 |
| `src/verify_data.py` | 의석수·무작위 법안 5건 대조표 생성 (`docs/verification.md`) |
| `src/metrics.py` | 이탈률·출석·분야·공동발의 상위 10·관계망·위원회별 선례 통계 (`data/metrics.sqlite`, `data/metrics/*.json`) |
| `src/build_government.py` | 정부조직법 현행 원문 → 정부 조직도 (`data/government.json`) |
| `src/verify_rules.py` | 제도 규칙 20개를 법제처 현행 원문과 대조 (`data/rules_institutional.json`) |
| `src/heuristics.py` | 정무 경험칙을 표결 데이터로 검증 (`data/rules_heuristic.json`) |
| `src/news.py` | 네이버 뉴스 동향 수집, 동명이인 판별, AI 사실 추출 |
| `src/engine.py` | 판단 엔진: 근거 묶음 → AI 판단(근거 번호 인용 강제) → 의원 단위 표 예상·캐스팅보트·처리 경로 |
| `src/moves.py` | 워게임 수의 제도상 가능 여부 검사(정족수는 규칙집에서 읽음) |
| `src/wargame.py` | 워게임 턴 진행 |
| `src/predictions.py` | 예측 기록·자동 채점·역검증 (`data/predictions.sqlite`, `docs/backtest.md`) |
| `src/llm.py` | Anthropic 호출, 호출별 토큰·비용 로그 (`data/logs/llm_usage.jsonl`) |
| `daily.py` | 매일 새벽 예약 실행 묶음 |
| `web/index.html` | 화면(빌드 없음) |
| `tests/` | 자동 테스트(`python -m pytest tests`). 테스트 데이터는 모두 가상 |

## 데이터 출처와 이용 조건

| 출처 | 쓰는 것 | 이용 조건 |
|---|---|---|
| 열린국회정보 Open API (국회사무처) | 의원 인적사항, 발의 법률안, 표결 | 공공데이터, 인증키 필요. 출처 표시 |
| 법제처 국가법령정보 공동활용 API | 헌법·국회법·정부조직법·국정감사및조사에관한법률 현행 원문 | 공공데이터. 원문은 `data/law_cache/`에 캐시(7일) |
| 네이버 검색 API(뉴스) | 기사 제목·날짜·언론사·링크 | 네이버 API 이용약관. 일 25,000회 |
| Anthropic API | 판단·사실 추출 | 유료. 호출마다 비용 기록 |
| 중앙선거여론조사심의위원회 | **자동 수집하지 않음** | — |

## 원칙

- **지어내기 금지**: 수집하지 않은 수치·발언·입장은 만들지 않는다. 빈 칸은 빈 칸(— 또는 미입력)으로 둔다. AI 결과는 `AI 추정`·`시뮬레이션` 표식(점선)으로 실제 기록(실선)과 구분한다. 근거 번호가 없는 AI 판단은 `근거 약함`으로 표시한다.
- **실존 인물 정보 처리**: 의원 카드에는 공개된 의정 활동과 공식 기록(인적사항 중 이름·정당·선거구·당선 횟수·위원회, 발의, 표결)만 담는다. 생년월일·연락처·가족·건강 등은 화면에 쓰지 않는다(API 원본은 `raw_json`에 남지만 화면과 판단에는 쓰지 않음). 보도 기반 정보는 `보도` 표식과 원문 링크를 붙인다. 경험칙의 출처는 직급·경력만 쓰고 이름은 쓰지 않는다.
- **저작권**: 기사 본문은 받지도 저장하지도 않는다. 제목·날짜·언론사·링크와 AI가 쓴 한두 문장 요약만 저장한다. 검색 API가 주는 요약문은 판별·추출에만 쓰고 저장하지 않는다.
- **수집 예절**: 공식 API만 쓴다. 요청 간격 최소 1초, 응답은 `data/cache/`에 캐시.
- **정치적 중립**: 정당 색은 실제 당색이 아니라 의석 순서대로 중립 팔레트를 쓴다. 판단 프롬프트에 어느 쪽에도 유리하게 쓰지 말라는 지시가 있고, 같은 근거·같은 규칙을 모든 세력에 적용한다.
- **정직한 평가**: 모든 예측은 날짜와 함께 `predictions.sqlite`에 남고 결과가 나오면 채점된다. 역검증 리포트는 기준 예측보다 못하면 그 사실을 첫 줄에 쓴다.
- **비밀 정보**: 키는 `.env`에만. `.gitignore`에 등록됨.

## 검증 현황

### 제도 규칙 (완료 기준 e)
`data/rules_institutional.json` 20개 규칙 전부 근거 조문이 달려 있고, 2026-10-27 법제처 현행 원문과 대조해 **20개 모두 검증됨**. 대조 방법: 각 규칙의 핵심 문구(must_contain)가 해당 조문 원문에 그대로 있는지 기계 검사.
발견 사항: 국회법 제85조의2(신속처리)가 2026.9.8 개정(2026.10.2 시행)으로 소관위 60일·법사위 30일로 짧아졌고, 기존 '부의 후 60일 내 상정' 조항이 삭제되어 '부의 간주 후 처음 열리는 본회의에 상정'으로 바뀌었다. 규칙집과 워게임은 개정 조문을 따른다.

### 국회 데이터 대조표 (완료 기준 a, b)
아직 미실시 — 열린국회정보 인증키가 필요합니다. 키 입력 후 `python src/update_assembly.py` → `python src/verify_data.py` 를 실행하면 `docs/verification.md`가 만들어지고, 공식 수치 칸을 채워 이 자리에 옮깁니다.

## 한계 (현재)

- 열린국회정보 서비스 코드·필드명은 실호출 확인 전(`docs/apis.md`).
- 위원회 위원 명단 API를 아직 찾지 못해, 위원회 구성은 의원 인적사항의 '소속위원회' 문자열로 대신한다(현재 시점만 정확, 과거 날짜 기준 위원회 구성은 부정확).
- 당적 변경일은 표결 기록의 '표결 당시 정당' 값으로 추정한다(변경 전후 표결일 사이 어딘가). 정확한 날짜는 `data/party_changes.csv`에 출처와 함께 입력하면 우선 적용된다. 보궐·사퇴·상실 날짜도 `data/member_terms.csv`로 보정한다.
- 정부 재의요구 이력은 API를 찾기 전까지 `data/vetoes.csv` 수동 입력.
- 정부 조직의 현직자 이름은 `data/government_people.csv`(출처 필수)로 입력해야 표시된다.
- 이해관계 집단 목록(`data/groups.csv`)은 초안이다. 확인 후 상태 칸을 바꿔 주세요.
- 지역 레이어는 지도 대신 시·도 단위 강조로 구현. 실제 지도는 선거구 경계 데이터(GeoJSON)가 필요하다.
- 워게임은 회기(정기회·임시회) 경계, 안건조정위 진행 중 표결 제한 같은 세부 절차는 아직 반영하지 않는다.
- 경험칙 H2~H8은 시제품(prototype.html)이 첨부되지 않아 비어 있다. H1 문구도 작업지시서의 예시에서 가져온 것이다.
- 화면 디자인은 시제품 없이 '작전상황실' 설명과 패널 목록(상황판, 의석도, 행위자, 정부 지휘계통, 처리 경로, 작전 입력, 작전 일지, 규칙집)만 보고 만들었다.
