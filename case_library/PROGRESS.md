# 진행 상황 (PROGRESS)

새 대화에서는 이 파일부터 읽고 이어서 한다. 작업지시서: 사용자 업로드 SPEC(국정 시뮬레이터 1단계 작업지시서 v1).
진행 규칙: 단계마다 짧게 보고 → 사용자 확인 후 다음 단계. 1·2단계는 10개로 먼저 해보고 확인받은 뒤 전체로 넓힌다.

## 결정 사항
- 프로젝트 위치: 저장소 루트에는 기존 게임(대통령으로_살아남기.py)이 있어서, 이 작업은 `case_library/` 아래에 둔다.
- 대상 판정: 목록상 게시일이 2022-05-10 ~ 2025-04-04 안인 데일리 오피니언(제N호) = 제495호~제618호, 124개.
  "월별·연간 통합" 보고서는 주간 호수가 아니라서 제외.
- 보고서 목록은 갤럽 리포트 목록 페이지(report.asp, 연도별 POST)에서 얻고, PDF 주소는 각 게시물 페이지의 첨부 링크에서 얻는다.
  (첨부 링크가 없으면 지시서의 주소 추정 방식으로 대체하도록 코드는 있으나, 아직 쓰인 적 없음)
